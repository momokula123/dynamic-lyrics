# 动态歌词画布（Dynamic Lyrics Canvas）

纯前端单文件实现的动态歌词动画页（`index.html`，无依赖、无构建）：canvas 逐字渲染 LRC
歌词，配镜头跟随、图形主题、涟漪/流星/粒子等氛围效果，底部自带进度线。

## 使用

1. 浏览器打开 `index.html`
2. 把 `.lrc` 歌词文件拖进页面 → 自动进入演示时钟播放
3. 再拖入一个音频文件（mp3 等）→ 歌词与音频同步播放
4. 点击画面 = 演示模式；底部有播放进度线

也可以把歌词直接写进源码里的 `DEFAULT_LRC`（标准 LRC 文本），打开即播。

> Resolume 文本框会把换行压成空格的场景已处理：`parseLRC` 会按 `[mm:ss.xx]`
> 时间戳自动重新分行，压扁的歌词一样能解析。

## 可调参数

源码 `CFG` 段（打开文件即见，均有注释）：

| 参数 | 含义 |
|---|---|
| charWindow / charFade / charEase | 逐字出字的窗口、单字淡入、字速节奏 |
| fontSize / textFloat / textBreathe | 字号、整体浮动、呼吸缩放 |
| enter / exit | 图形进场 / 退场时长 |
| camPre / camSpeed | 镜头预判下一句比例、跟随速度 |

## 集成

`DEFAULT_LRC` 是唯一入口：页面加载后解析它并自动开始。把它替换成任意 LRC
文本（或置空等待运行时注入）即可嵌入到自己的系统里。
